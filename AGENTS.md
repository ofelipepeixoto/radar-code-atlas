# Radar Code Atlas — contrato de trabalho
Código original de Carlos Felipe. GitNexus é referência estudada, não dependência ou código redistribuído. Não atribuir clean room jurídica.
Usar branches e PRs; nunca fazer merge sem revisão humana e autorização aplicável. Não executar fontes adquiridas, scripts, imports ou configurações do alvo. Não copiar credenciais ou fontes privadas para Git/CI.
Primeiro marco: aquisição por ID + SHA completo, consultas locais com evidências e cobertura explícita. Sem painel, agente autônomo, VPS, Sites, Supabase, n8n ou mudanças no WhatsApp.
Testes: `npm run check && npm test`. Fixture não equivale a integração real. Não mudar expected para esconder falha.
